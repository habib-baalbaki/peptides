# NXT Peptides Canada: website

A static storefront built from `research/canadian-peptide-competitors.md` (Section 0 positioning, Section 3 blueprint) and `NXT_Catalogue_0426.pdf`.

**Positioning used across the site:** Canadian-based · UK-tested & validated · Bringing NXT to Canada. The site never claims "Made in Canada".

## Build and run it

The root HTML files are the source. A zero-dependency Node script (Node 18+) pre-renders the header, footer, product grids, SEO tags and structured data into them, generates one page per product, and mirrors everything Cloudflare serves into `docs/`:

```sh
npm run build    # or: node scripts/build.mjs
npm run check    # link checker + JSON-LD / sitemap validation on docs/
python3 -m http.server 8000 -d docs
# open http://localhost:8000
```

**Run `npm run build` after every change** to `assets/js/data.js`, a page or the product template, and commit the result, including `docs/`. The build is idempotent: a second run changes nothing.

How it works:

- In the root pages, everything between `<!-- nxt:NAME -->` and `<!-- /nxt:NAME -->` is generated. Don't edit inside those markers. Everything else (titles, meta descriptions, page copy) is hand-written and kept as is.
- `products/<id>.html` is generated from `templates/product.html` for every product in `data.js`. Edit the template, not the generated pages. Pages for removed products are deleted.
- `assets/js/render.js` holds the HTML templates (cards, header, footer, product details). The build and the browser both use it, so the static HTML and the JS-rendered HTML can't drift apart.
- Canonical URLs, `og:url` and the sitemap use the extensionless URLs Cloudflare actually serves (`https://nxtcanada.ca/products/bpc157`), because Cloudflare 307-redirects `*.html` to them.
- The build stops if a title, description or JSON-LD block contains "Made in Canada", "pharmaceutical grade", "Health Canada approved" or "for human use". For the same reason, the FAQ question "Are your products made in Canada?" is left out of the FAQPage schema. It still shows on the page.
- `scripts/lastmod.json` records a hash per page, so sitemap `lastmod` dates only change when a page actually changes.

## Orders & newsletter backend

Checkout and the homepage newsletter post to a small Cloudflare Worker (`worker/index.js`). It runs on the same domain at `/api/*`, and everything else is still served from `docs/`.

- `POST /api/order` checks the order, recalculates the totals from the catalogue (the browser's numbers are never trusted), gets the live crypto rate, saves the order to D1 and emails it to you. The customer's cart is only cleared after this succeeds. If it fails, they keep their cart and get an "email us your order" link instead.
- `POST /api/subscribe` saves newsletter emails to D1, one row per address.
- `GET /api/admin/export?type=orders` (or `type=subscribers`) downloads a CSV. It needs your admin token, either in an `Authorization: Bearer <token>` header or as `&token=<token>` on the URL.
- `worker/catalogue.js` is generated by `npm run build` from `assets/js/data.js`. Don't edit it by hand.

### One-time setup (do this before the next deploy)

The Worker won't deploy until steps 1–2 are done, because `wrangler.jsonc` still has a placeholder database id.

1. `npm install`, then `npx wrangler login`.
2. `npx wrangler d1 create nxt-orders`. Copy the `database_id` it prints into `wrangler.jsonc`, replacing the zeros.
3. `npx wrangler d1 migrations apply nxt-orders --remote` creates the tables.
4. **Email Routing:** Cloudflare dashboard → nxtcanada.ca → Email → Email Routing → enable it (Cloudflare adds the MX/SPF records). Under **Destination addresses**, add `nxtcanada@outlook.com` and click the link in the verification email. Order alerts are sent from `orders@nxtcanada.ca` to that address. If you want a different inbox, change both `destination_address` and `ORDER_TO` in `wrangler.jsonc`.
5. `npx wrangler secret put ADMIN_TOKEN`, then paste a long random password. You'll use it to download orders: `https://nxtcanada.ca/api/admin/export?type=orders&token=<token>`.
6. Run `npm run build`, commit and push (or `npx wrangler deploy`).
7. Place a real test order on the live site and confirm the alert email arrives. Check the spam folder the first time and mark it "not junk".

### Run it locally

```
npx wrangler d1 migrations apply nxt-orders --local
echo ADMIN_TOKEN=localtest > .dev.vars
npx wrangler dev          # http://127.0.0.1:8787
```

Locally, order emails are written to `.wrangler/tmp/email/` instead of being sent.

### Day to day

- Each order email shows the exact crypto amount and wallet. Match incoming payments by amount, then ship.
- First-order discount: the email flags it. Check the export to make sure that email address hasn't ordered before.
- The order `status` column starts as `awaiting_payment`. There's no admin page yet, so keep track of shipping in your own records or update the column with `npx wrangler d1 execute`.

## Before launch checklist

Everything marked `TODO` in `assets/js/data.js`:

- [x] **Analytics.** Cloudflare Web Analytics runs with automatic setup, so Cloudflare injects the beacon itself. Leave `cfAnalyticsToken` empty unless automatic setup is turned off; setting both would double-count.
- [ ] **Search engines.** Submit `https://nxtcanada.ca/sitemap.xml` in Google Search Console and Bing Webmaster Tools, then check that the product pages get indexed.

- [ ] **Prices.** Current prices are placeholders near the Canadian market median. Enter real prices, then set `pricesArePlaceholders: false` to remove the yellow preview bar.
- [ ] **UK lab name** (`ukLabName`), plus a COA PDF for each batch on the Lab Results page and the product pages.
- [ ] Free-shipping threshold, flat shipping rate and same-day cutoff time.
- [ ] Real email address on your own domain, a Canadian phone number, and the official domain.
- [ ] **Checkout.** The current flow emails an order request (`mailto:`) and asks for Interac e-Transfer. Replace it with a real checkout (Shopify or WooCommerce, with a processor that accepts this category) before taking real orders.
- [ ] **French version.** Québec's Charter of the French Language (Bill 96) requires French on commercial websites.
- [ ] Confirm stock is held in and shipped from Canada. The site says "Shipped within Canada by Xpresspost".
- [ ] Get written authorization from NXT to present yourselves as NXT in Canada.
- [ ] Newsletter and contact forms are front-end only. Connect them to an email tool (e.g. Klaviyo or Mailchimp) or a form handler.
- [ ] Real product photography. The current images are cropped from the PDF.
- [ ] **Legal review** of all copy and policies by a Canadian health/regulatory lawyer. Health Canada's April 2026 advisory says "research use only" labels don't make unauthorized peptides legal to sell, and most of this catalogue is on its seized-products list (see the research doc).

## Deliberately left out

- **Reconstitution / "peptide calculator".** Competitors use one, but it works out injection draw volumes, which reads as human-use dosing guidance. That conflicts with the research-only positioning and would add regulatory risk.
- **Dosing, protocols and health or weight-loss claims.** Product copy uses research-model language only.
